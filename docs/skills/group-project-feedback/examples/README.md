# Feedback Examples

Place your real past feedback files here so the AI can learn your voice.

## Requirements
- **Minimum:** 3 files
- **Format:** `.md`, `.txt`, or `.docx`
- **Content:** Copy-paste actual feedback you have given to group members on their reports/assignments
- **Language:** Vietnamese (matching how you normally write feedback)

## What the AI extracts from these files
- Your vocabulary patterns and recurring phrases
- How you phrase criticism (direct? suggestive? rhetorical?)
- How you phrase praise (or whether you skip praise entirely)
- Your sentence structure and formality level
- Any signature expressions or quirks

## Example file naming
```
feedback-report-nhom1.md
feedback-baitap-lan2.txt
nhanxet-phan-ketluan.md
```

The more examples you provide, the more accurately the AI will match your voice.
